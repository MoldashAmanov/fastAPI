pip3 install -r requirements.txt

uvicorn main:app --reload запускает сервер с автоперезагрузкой
http://localhost:8000/docs swagger UI (автодокументация)
http://localhost:8000/redoc redoc (альтернативная документация)

async асинхронные (для операций ввода-вывода)
def синхронные (обычные)

Если функция работает с БД, файлами или внешними API - async def

Типы параметров
path-параметры - часть URL: /users/123
query-параметры - после ?: /users?age=25
body-параметров - тело запроса (JSON)

pydantic - библиотека для валидации данных. Она проверяет:
- типы данных
- обязательность полей
- длину строк
- диапазоны чисел
- форматы (email, url)
